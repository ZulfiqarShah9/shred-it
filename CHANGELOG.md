# Changelog

## 1.0.0

- Floating frameless Shred-it widget built from `paper-shredder-widget.html`.
- Two-stage delete: shred moves files into a private bin; burn permanently overwrites and deletes them.
- Restore files from the tray/menu-bar menu.
- Tray/menu-bar controls, global shortcuts, single-instance handling and dock/taskbar reopen.
- First-run information screen explaining permanent deletion (no confirmation prompts).
- Dark/light themes, shred speed, secure-delete toggle, auto-empty and bin capacity settings.
- Sober slate/steel shredder logo for app, tray and installers.
- macOS universal DMG and Windows x64 NSIS installer.

Tested on macOS. Windows build is cross-compiled but not yet manually tested.
